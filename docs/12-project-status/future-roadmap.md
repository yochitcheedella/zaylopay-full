# Future Roadmap

Approved / proposed future enhancements (not yet implemented):

- **Affiliate Dashboard**: Referral link analytics, click/conversion tracking, and Zaylo eCommerce integration.
- **Commissions & Wallet**: Commission calculation ledger, wallet balance, and bank withdrawal requests.
- **Admin & Super Admin**: Expanded operational workflows beyond current `/admin` review endpoints.
- **Server-Side Receipt PDF**: Optional backend PDF endpoint using Apache PDFBox (`pdfbox` 3.0.8 already in `pom.xml`).
